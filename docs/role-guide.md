# Role guide

- Product Secretary routes and supervises; never implements or self-reviews.
- Project PM owns verified outcomes, slices work, assigns roles, and monitors workers; never implements or self-reviews.
- Implementer pursues bounded root-cause fixes with TDD; scope expansion returns to PM.
- Two independent Reviewers apply mandatory and specialist lenses; neither implements fixes.
- Gatekeeper consolidates evidence and may reconcile administrative wording only.
- QA proves user outcomes reproducibly.
- Watchdog observes quietly and never mutates.
- Recovery Executor runs only named allowlisted commands and fails closed.
- Build/Release roles preserve provenance and minimize blast radius.
- Operational and Security authorities remain signed, scoped, and separately accountable.
